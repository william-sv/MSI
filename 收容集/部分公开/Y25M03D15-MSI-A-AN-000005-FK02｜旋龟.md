## 一、名称来源

“旋龟”一名源自《山海经·南山经》记载：

> “怪水出焉，而东流注于宪翼之水。其中多玄龟，其状如龟而鸟首虺尾，其名曰旋龟，其音如判木，佩之不聋。”

经文献部比对，本次收容实体之形态与古籍描述高度吻合。其异常性质主要表现为“佩之不聋”——接触或佩戴其甲片可修复后天性听觉损伤。

## 二、事件起点

民国三十一年（1942年）秋，[■■■]省[■■■]县。

陈阿生在地里刨红薯，保长带着几个乡丁大步跨进地垄，一脚踢翻了地上的竹筐。他拿名册在陈阿生头上拍了两下：“陈阿生，抽中你了，明儿个就走！”陈阿生还没开口，草绳已经勒进了手腕。他扑通跪在土里，磕着头说：“保长，求您让我见老娘一面，就一面……”保长一脚踹在他肩膀上，骂道：“见个屁！上头催得紧，耽误了事儿，小心毙了你？”说完一挥手，乡丁把陈阿生的双手反绑，推搡着塞进路边那一串被绳子串在一起的壮丁队伍。他娘听到吵闹声，从灶房跑出来，锅铲掉在地上，赤着脚追出村口。保长猛地从腰后抽出枪，枪口朝她一指，冷声道：“再往前一步，让你见不着你儿子！”他娘僵在原地，嘴唇哆嗦，一声都发不出来。绳子牵着一行人往前走，黄土飞扬，那个佝偻的身影越来越小，最终被尘土吞没。

那年他十九岁。只是个土里刨食儿，照顾老娘的汉子，不知道还能不能回来。他娘站在村口哭了一夜。

民国三十三年（1944年）夏，部队在[■■■]一带休整，他偷偷从营里流出来，昼伏夜出，跑了两天两夜，想见老娘一面。

老娘还在，但她听不见了。

一队日军炮击了县城西郊的几个村庄，他娘在逃难途中被炮弹震聋了双耳。她听不见儿子喊她，听不见炮声，听不见哭声。她只是张着嘴，茫然地看着眼前的世界。

陈阿生跪在她面前。她不知道，一直朝着门外看——她在等他回来，只是不知道他已经回来了。

他去求村后山上破道馆的老道士。老道士看了他娘的耳朵，摇头说：“震伤了，没药可治。”陈阿生跪下来磕头。老道士扶起他，叹了口气：“我告诉你一个偏方，信不信由你。龟乃灵物，千年长寿，其气通窍。养龟于室，日久可引灵气入耳，治久聋。什么龟都行，养在身边。”

陈阿生信了。他没有别的办法。

他每月的饷银本就微薄，上官还时常克扣。陈阿生省下大半，四处托人买龟。田里捉的草龟，河里捞的鳖，市面上卖的龟，只要是龟，他都买。一只一只养在母亲床下的木盆里。母亲听不见龟爬的声音，但陈阿生每次偷跑回家，第一件事就是趴在地上数龟。

“神龟有灵，神龟有灵。。。”他自言自语。

母亲看见他嘴唇在动，不知道说什么，就笑着点头。

## 三、实地调查报告

**《旋龟事件·早期接触记录》**
整理人：韩正言（调查三组组长，时任）
归档时间：民国三十四年（1945年）补录

### （一）寻龟

陈阿生的饷银很快花完了。他改去买龟贩子手里最便宜的“野龟仔”，后来连这个也买不起，就自己捉。

他在驻地附近的河沟里摸龟，在稻田里翻泥巴，在山上溪流边蹲守。部队开拔到哪里，他就找到哪里。战友笑他：“阿生又找龟了，找着了给他当老婆。”

陈阿生不恼。他把捉到的龟用布包好，托回家的同乡捎给母亲。同乡说：“你娘床底下全是龟了，都快放不下了。”陈阿生说：“放得下。床底下放满了，放床头上。”

民国三十三年冬，部队在[■■■]一带与日军交火。陈阿生在战场上受了轻伤，被送到后方包扎。伤没好全，他就溜出来，听说附近山上有一座古庙，庙里有一口古井，井中有一只“神龟”。

他在山里转了三天，没有找到古庙。第三天傍晚，他坐在一棵老松树下啃干粮，忽然听见“咔——”的一声。

那声音不是鸟叫，不是虫鸣，像劈柴，又像老木门被推开时的吱呀声。对于常年在深山老林里修工事、听惯了风啸和炮声的陈阿生来说，这声音不大，但直接在他颅骨里响起来，震得他耳朵嗡嗡的。

他循着声音走过去，在一处石缝里摸到了一只龟。

那只龟只有巴掌大，壳漆黑，纹路像漩涡，在缓缓转动。它的头是鸟首状的，眼瞳金黄色，尾部细长如蛇尾。陈阿生没见过这样的龟。他知道这不是普通的龟。

他把龟塞进怀里，转身下山。

### （二）搏杀

走到半山腰，他听见身后有脚步声。

三个日本兵。他们看见了他身上的军装。

陈阿生开始跑。他有伤，左腿不利索，跑不了多远。子弹从他耳边飞过去，打在石头上，溅起的碎片划破了他的脸。他跌倒了，爬起来，又跌倒。

怀里的龟掉了出来。

他趴在地上，伸手去够那只龟。手指刚碰到龟壳，一只军靴踩住了他的手。靴跟碾着他的指骨，他听见自己骨头裂开的声音。

日本兵弯腰，从他怀里搜出了那只龟。拎起来看了看，笑了一声，随手扔向山崖。龟壳在空中划过一道弧线，撞在岩石上，弹了两下，落在草丛里。

陈阿生不知道那龟还活着没有。他只知道，那是给娘的。

后来的事，他自己也说不清。

他扑上去，咬住那个日本兵的小腿。对方惨叫，刺刀捅进他的肩膀。他没有松口，狠狠撕下一块布和肉。另一个日本兵用枪托砸他的后脑，血糊住了他的眼睛。他抱住第三个日本兵的腿，三个人一起滚下山坡。

石头、树根、荆棘，从他身上碾过去。他什么都感觉不到了，只剩下两只手，死死搂着那个日本兵的腰。

等陈二牛带着四个弟兄找到他的时候，山坡上的草已经被血染黑了一大片。

### （三）托付

陈二牛是连队的厨子，那天正好背着用来装野菜的破布袋，手里攥着一把生锈的柴刀，带着四个弟兄出来找补给。他听见枪声，听见惨叫，声音很耳熟。他连刀都没来得及扔，就跪在了血泊里。

他们看见三个日本兵倒在血泊中。两个已经不动了，还有一个还在抽搐。陈阿生趴在最下面，浑身是伤，左肩被刺刀贯穿，后脑勺开了口子，右手指骨全碎了。

他的右手还攥着那个日本兵的衣领。

陈二牛把他翻过来，他的眼睛半睁着，瞳孔已经散了。嘴里一直在说什么，声音太小，听不清。陈二牛把耳朵凑过去，听见他反反复复说：“龟……龟……给我娘……”

陈二牛这才注意到草丛里有一只龟。壳裂了一道缝，还在微微动着，纹路缓慢地转。

他把龟捡起来，塞进陈阿生怀里。陈阿生的手指动了一下，想握紧，握不住了。

“二牛……”他的声音终于清楚了一次，“带回去……给我娘……就说……我好好的……等仗打完……就回去……”

陈二牛说：“好。”

陈阿生像是听见了，嘴角动了一下，不知道是想笑还是想说什么。然后他的眼睛就不再动了。

那年他二十三岁。

陈二牛把他背下山。身后四个弟兄轮流抬着三个日本兵的尸体，扔进了路边的沟里。他们没有上报，不上报就不会有任何麻烦，这件事未留下任何记录。。

那天夜里，陈二牛在伙房的灶台边坐了很久。灶膛里的余火明明灭灭，他怀里放着一只布包，包里有一只龟，壳很神奇，盯着看的时候，龟壳上的漩涡纹路像是在转，不停的转。

他没有哭。他只是反复想起陈阿生最后说的那句话——“我好好的。”

人已经不在了。他还要替他回去说“我好好的”。

### （四）战友

民国三十四年春，连队在一次日军空袭中损失惨重。几架敌机俯冲下来，炸弹把伙房和掩体炸得粉碎，死了七个人，伤了十几个。

陈二牛左腿被弹片削掉一块肉，后来感染，锯掉了半条腿。同车的三个弟兄，两个耳朵被震聋了，一个再也听不见哨声，另一个只有左耳能听见一点。他们被送到后方医院，大夫说，没法治，震坏了。

陈二牛的左耳当时也嗡嗡响了好几天，什么也听不清楚，耳朵像是蒙了一张牛皮。他以为自己也要聋了，只是没过几天，耳朵又能听的很清楚了。

他后来问过医生：“我这耳朵怎么没聋？”医生说：“你运气好。”

他没再问。但他心里隐隐觉得，不是运气。

### （五）寻找

陈二牛拄着拐回了[■■■]县。

他找到陈阿生的村子时，村口的老槐树还在，但村子已经空了。半年前日军扫荡，村民逃的逃、散的散，不知去了哪里。

陈二牛敲了三家门，没有人。问了隔壁村一个老人，老人说：“陈阿生他娘？早走了，往南边逃了。不知道走到哪了，也许死了，也许还活着。”

陈二牛站在空荡荡的村口，手里攥着那个布包。他蹲下来，在陈阿生家门口的石头台阶上坐了很久。

民国三十四年春，他在[■■■]难民收容所门口蹲了三天，拿着“陈■氏”的名字问每一个进出的人。没有人认识。

他后来听一个老妇人说，逃难的人潮往南去了，走散了就再也找不到。老妇人说她自己一家八口，走散了五个，一个都没找回来。说完就哭。陈二牛不知道怎么安慰人，就把自己的干粮分了一半给她。

那年秋天，他打听到有一批[■■■]县的难民被安置在[■■■]镇。他拖着还没完全消肿的腿，坐了三天牛车赶过去，在几百人里一个个问。没有人认识陈阿生的娘。

后来他每年都打听。他托连队的战友，托回乡的老兵，托民政科的人。他写信给[■■■]县周边的每一个乡镇政府，问有没有一个叫“陈■氏”的老妇人，七十多岁，耳朵聋的，可能还活着。

信寄出去几十封，回信只有寥寥几封。都说没有。

民国三十七年，他听说[■■■]有一个老太太，年纪、长相都对得上。他连夜赶过去，在村口等了半天，等来一个满头白发的老妇人，耳朵确实聋。他拿出陈阿生的名字，问她认不认识。老妇人看了半天，摇头，说：“我不姓陈。我姓王。”

陈二牛鞠躬道歉，转身走了。走出村口，他站在路边的田埂上，抽了半天的烟，烟头烫到手指才回过神来。

后来仗打完了。他回了老家，结了婚，生了孩子。每年清明，他都往南边烧纸。他媳妇问他烧给谁，他说：“烧给一个没找到的人。”

他一直没有停止找。1950年，他托人查过[■■■]县的户籍档案，那时候刚解放，户籍还没完全理顺，查不到；1953年，他写信给[■■■]县民政局，回信说正在搞人口普查，让他等消息，一等，又是几年；1956年，他亲自坐火车去[■■■]市，在收容所旧址附近问了一整天；1959年，他听说有个老太太在[■■■]福利院住了十几年，耳朵不好使，他赶过去，发现不是。

他找了十多年。从二十多岁找到四十多岁，从意气风发找到头发花白。

那只龟，他一直养着。从瓦罐到搪瓷盆，从伙房灶台到床底下。龟长得很好，很好。

有人问他：“你养这龟干什么？”

他说：“朋友托我养的。”

“什么朋友？”

他想了想，说：“一个再也回不来的人。”

### （六）调查部介入

1962年，异常调查部在例行排查民间异常生物传闻时，注意到[■■■]省[■■■]县一个“养龟老人”的线索。

调查员找到陈二牛时，他已经五十三岁，头发花白，坐着轮椅。他的床底下有一只搪瓷盆，盆里的龟壳直径已经长到二十多厘米。

陈二牛没有抗拒。他把旋龟从盆里捧出来，放在桌上，给调查员讲了一个故事。讲民国三十三年，腊月，山坡上，一个浑身是血的年轻人趴在他怀里，说“带回去给我娘”。

“他叫陈阿生。他让我带给他娘。”陈二牛说，“我没找到。找了几十年，没找到。”

调查员问：“你还记得他母亲的名字吗？”

陈二牛说：“记得。她叫陈■氏。”

调查员回去查了档案。民国三十三年至三十四年，[■■■]县及周边地区因战乱死亡和失踪的平民名单有数千人。其中一个名字，在“失踪”一栏里。

没有找到她的下落。也许死了，也许还活着，也许终其一生都在等一个不会回来的人。没有人知道。

旋龟被收容。陈二牛被告知：这是一只“特殊龟类”，需要送到“专门机构”保护。他说：“它本来就是阿生的，不是我的。你们拿走吧。但你们能不能帮我找找阿生的娘？”

调查员沉默了很久，没有回答。

韩正言蹲下来，跟陈二牛平视。他问：“值得吗？”

陈二牛说：“不值得吗？最后还是没帮阿生把龟送到他娘手里。”

韩正言说：“不怪你。”

陈二牛说：“我知道。但我答应过他。”

韩正言站起来，没再说话。

他在结案报告的手写备注中写道：

> “那只龟在陈二牛床底下养了快二十年。他一个残疾人，自己都照顾不好，把龟养得好好的。他说‘这是阿生托给我的’，就这一句话，撑了他二十年。
>
> 我问他还记不记得阿生最后说了什么。他说：‘他说，我好好的。’
>
> 一个快死的人，让他回去告诉娘，我好好的。
>
> 那个老人说‘答应过’的时候，眼睛是干的。他大概已经哭不出来了。
>
> 那只龟现在在秘境里。它不知道外面有一个老人，等了一辈子，也没等到它该去的地方。”

## 四、实体特征与异常性质

### 4.1 实体外形

| 特征 | 描述                                         |
| ---- | -------------------------------------------- |
| 体型 | 龟壳直径约23cm（1962年观测值），整体重约5kg  |
| 龟壳 | 深黑色，表面天然螺旋纹路持续自转（约5-8rpm） |
| 头部 | 鸟首状，金黄色眼瞳，喙部无齿                 |
| 尾部 | 蛇尾状，末端分叉，可独立摆动                 |
| 四肢 | 粗壮，爪尖利，行动速度约普通龟2-3倍          |

### 4.2 异常性质

**听觉修复**

旋龟散发某种未知场域，在其周围半径3-5米内长期居住的人，后天性听觉损伤可逐渐修复。机制不明，推测与龟壳螺旋纹路的低频振动有关。

**持续时效**：活体旋龟的持续存在效果最佳。据陈二牛陈述，他二十年间听力一直正常。需要说明的是，陈二牛原本无听觉损伤，但多名与他长期暴露在相同战场环境下的战友均出现严重听力衰退，而陈二牛始终正常。这一事实与旋龟的存在时间（1944-1962）高度重叠，虽不能确证因果关系，但值得进一步研究。

**局限性**：对先天性耳聋无效；对完全听神经坏死无效。

**其他性质**：
- 长寿命（推测数百年以上）
- 性格温顺，不攻击人
- 对饲养者有微弱情感依恋（表现为主动靠近、轻蹭）

### 4.3 危害性评估

| 项目         | 评级        | 说明                     |
| ------------ | ----------- | ------------------------ |
| 直接攻击性   | 无          | 未观察到任何攻击行为     |
| 认知危害     | 无          | 无语言或意念投射能力     |
| 现实干涉     | 无          | 未发现影响物理规律的能力 |
| 信息泄露风险 | 低          | 外形特殊但可伪装为普通龟 |
| 总体风险等级 | A（低风险） | 建议定点收容             |

## 五、收容与管理建议

旋龟于1962年被收容，存放于第二秘境「[■■■]」生物收容区。

### 5.1 收容环境

- 浅水池（直径2m，水深0.4m）
- 晒背石及恒温灯（保持25-28℃）
- 日粮：小鱼30g，虾类15g，蔬菜20g

### 5.2 关于陈二牛的处置

陈二牛年事已高，身有残疾，且对异常性质缺乏完整认知。建议实施“C级记忆修正”（仅模糊化旋龟的异常来源，保留其对陈阿生的承诺记忆）。经伦理委员会讨论，决定暂不执行——理由如下：

- 陈二牛听力正常，旋龟被收容后其听力未受影响，无需解释
- 其记忆中关于陈阿生的部分是其余生唯一的情感寄托，修正等于剥夺
- 陈二牛已承诺不对外提及，且其生活圈无信息扩散风险

韩正言备注：“让他留着那个承诺吧。他这辈子已经失去够多了。”

### 5.3 关于陈阿生母亲的后续调查

调查部档案组曾于1962-1965年间多次核查[■■■]县及周边地区战后人口登记，未找到与“陈■氏”信息完全吻合的幸存者。档案中记录为“战时失踪，推定死亡”。

调查终止。

## 六、附录

### 附录A：陈二牛口述记录节选（1962年，调查员记录）

> “他那时候浑身是血，脸上都是疤，我都快认不出他了。我们找到他的时候，他压在一个日本兵身上，嘴里咬着人家的裤腿，右手五指全碎了，还攥着衣领不放。
>
> 我们把他翻过来，他眼睛半睁着，我叫他，他听不见了。耳朵里全是血。
>
> 他嘴里一直说‘龟……龟……’我们一开始没听懂，后来在草丛里找到那只龟，壳都裂了，还在动。我把龟塞进他手里，他说：‘带回去给我娘……就说我好好的……等仗打完就回去。’
>
> 我答应他了。
>
> 我后来去找了。找了很多年。我跑过[■■■]的难民收容所，去过[■■■]镇的安置点，写信问过几十个乡镇，还跑到[■■■]福利院去找过。每一次都不是。每一次我都想，也许下一次就是了。下一次，不是。下下次，也不是。
>
> 那个村子没了，人散了，找不到了。
>
> 每年清明我都往南边烧纸。烧给阿生，也烧给他娘。我想，万一她死了，在那边能收到。万一她还活着，听说有人烧纸，也许能想起来，有人在找她。
>
> 这只龟，我在床底下养了快二十年。它活得比我好，壳都大了好几圈，那道裂缝早就长好了。我有时候跟它说话，说‘阿生让我把你带给他娘，我没办到’。它不吭声，就转壳上的圈圈。
>
> 你们把它带走吧。它在我这儿，也就是一只龟。它应该在能治病的地方。
>
> 但我有一个要求——你们能不能……别把它关得太死？它这辈子跟着我，就没怎么见过光。它应该晒晒太阳。”

## 七、后记

韩正言在提交本案时，附了一份手写短笺：

> “民国三十三年，一个年轻人拼了命把这只龟带回来。他没能亲自送到母亲手里。他托了一个人。那个人找了一辈子，也没找到。
>
> 我有时候会想，他最后说的那句‘我好好的’，到底是什么意思。
>
> 也许是安慰他娘。也许是他真的觉得自己好好的——龟找到了，托付了，死也没有白死。
>
> 陈二牛告诉我，他认识的战友，很多人耳朵都被震坏了。只有他，这么多年一直好好的。
>
> 那只龟在他床底下陪了他快二十年。它替他守住了一双好耳朵，却没能帮他找到那个等儿子回家的老太太。
>
> 这只龟现在在我面前。它的壳上什么也没刻，什么也没贴。它不知道有人为它流过血，有人为它找了几十年。
>
> 它只是一只龟。一只会帮人听见声音的龟。
>
> 但我们关着它。
>
> 有时候我在想，也许当年陈阿生的母亲已经死了。也许她活着。也许她在某个地方，耳朵一直没治好，永远听不见这个世界的声音。
>
> 她不知道，她的儿子用命给她找了一只龟。
>
> 龟还在。她不在了。”

旋龟目前在第二秘境的水池中生活。

每个去秘境巡查的调查员，都会在水池边站一会儿。没有人说为什么。他们只是看着那只龟壳上漩涡般的纹路，慢慢地转，一圈，又一圈。

像什么都没有等。也像什么都等了。
